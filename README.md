## English

This fork contains the model catalog from [Elaina69/Yes-Steve-Model-Repo](https://github.com/Elaina69/Yes-Steve-Model-Repo). The companion [OpenYSM-Updated fork](https://github.com/IsSlashy/OpenYSM-Updated) provides unofficial experimental Fabric JARs for the exact Minecraft versions listed above. The original model files are unchanged; one catalog is used across these ports. See [COMPATIBILITY.md](COMPATIBILITY.md) for the tested scope and limits.

Install the matching JAR on the server and every client. Download the [tested model ZIP](https://github.com/IsSlashy/Yes-Steve-Model-Repo/archive/1749b46467acea11694891c01ede24914b22dc6c.zip), extract the outer repository folder, then copy its model files and category folders into the server's `config/yes_steve_model/custom/`. Individual model ZIPs may remain zipped. Clients download the models automatically from this mod's server. Each Release includes installation instructions in all four languages.

## Français

Ce fork contient le catalogue de [Elaina69/Yes-Steve-Model-Repo](https://github.com/Elaina69/Yes-Steve-Model-Repo). Le [dépôt du mod associé](https://github.com/IsSlashy/OpenYSM-Updated) fournit les JAR Fabric expérimentaux non officiels pour les versions exactes de Minecraft indiquées ci-dessus. Les fichiers de modèles restent inchangés ; le même catalogue sert pour ces portages. Le [guide de compatibilité](COMPATIBILITY.md) détaille les tests et leurs limites.

Installe le JAR correspondant sur le serveur et chaque client. Télécharge le [ZIP des modèles testé](https://github.com/IsSlashy/Yes-Steve-Model-Repo/archive/1749b46467acea11694891c01ede24914b22dc6c.zip), décompresse le dossier global du dépôt, puis copie ses fichiers de modèles et dossiers de catégories dans `config/yes_steve_model/custom/` sur le serveur. Les ZIP de modèles individuels peuvent rester compressés. Les clients téléchargent automatiquement les modèles depuis le serveur équipé du mod. Chaque Release contient les instructions dans les quatre langues.

## 简体中文

本分支保留了 [Elaina69/Yes-Steve-Model-Repo](https://github.com/Elaina69/Yes-Steve-Model-Repo) 的模型目录。[配套模组仓库](https://github.com/IsSlashy/OpenYSM-Updated) 为上表中确切的 Minecraft 版本提供非官方实验性 Fabric JAR。原始模型文件未作修改，这些移植版本共用同一模型目录。测试范围与限制请参阅[兼容性说明](COMPATIBILITY.md)。

服务器及每个客户端都需安装对应版本的同一个 JAR。下载[已测试的模型 ZIP](https://github.com/IsSlashy/Yes-Steve-Model-Repo/archive/1749b46467acea11694891c01ede24914b22dc6c.zip)，先解压仓库外层文件夹，再将其中的模型文件与分类文件夹复制到服务器的 `config/yes_steve_model/custom/`。单个模型的 ZIP 可以保持压缩状态。客户端会从安装了该模组的服务器自动下载模型。每个 Release 均提供上述四种语言的安装说明。

## 日本語

このフォークは [Elaina69/Yes-Steve-Model-Repo](https://github.com/Elaina69/Yes-Steve-Model-Repo) のモデルカタログを保持しています。[対応する Mod リポジトリ](https://github.com/IsSlashy/OpenYSM-Updated) は、上表の正確な Minecraft バージョン向けに非公式・実験用 Fabric JAR を提供します。元のモデルファイルは変更しておらず、各移植版で同じカタログを使用します。検証範囲と制限は[互換性ガイド](COMPATIBILITY.md)を参照してください。

対応する同じ JAR をサーバーとすべてのクライアントに導入します。[検証済みモデル ZIP](https://github.com/IsSlashy/Yes-Steve-Model-Repo/archive/1749b46467acea11694891c01ede24914b22dc6c.zip) の外側のリポジトリフォルダーを展開し、中のモデルファイルと分類フォルダーをサーバーの `config/yes_steve_model/custom/` にコピーしてください。個別モデルの ZIP はそのまま利用できます。クライアントはこの Mod を導入したサーバーからモデルを自動ダウンロードします。各 Release に上記 4 言語のインストール手順があります。

from that compatibility guide; model files remain unchanged.
